# XPhotos

Native Android photo gallery and curation app built with Kotlin, Jetpack Compose, and Material 3.

## Features

- **Library**: Adaptive staggered masonry & square grid views, category/favorite/recent filtering, sorting (`Newest first`, `Oldest first`, `Title A–Z`, `By category`), multi-select batch actions (favorite, add to album, delete), and Memories card.
- **Discover**: Featured collection carousel, Stories strip, Curated collections, Mood cards, Trending searches, Editors' picks, Photo of the day, and Category browser.
- **Search**: Live smart search across titles, tags, locations, photographers, and categories, with recent searches, trending tags, and dynamic category filtering.
- **Albums**: Smart albums (`Favorites`, `Recently Added`, `Camera Roll`, `All Photos`), custom user albums with emoji covers, rename/delete management, and multi-photo picker.
- **Photo Viewer**: Fullscreen horizontal pager with double-tap zoom, EXIF camera metadata sheet, related photos, native Android sharing, download manager export, favorite toggle, and album assignment.
- **Slideshow**: Fullscreen Ken Burns crossfade & zoom slideshow with progress bar and playback controls.
- **Camera**: Native CameraX photo capture with front/back flip, flash cycling, rule-of-thirds grid overlay, and Android Photo Picker import.
- **You / Profile**: Storage breakdown insights, System/Light/Dark theme switching, Comfortable/Compact grid density, autoplay & metadata toggles, and DataStore persistence.
